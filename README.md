# ShopHub - E-Commerce Template

This is a demonstration template for a modern storefront built with Next.js, React, Tailwind CSS, and TypeScript. It includes example product pages, cart flow, and demo integrations (Supabase, Razorpay). The repository has been refactored to "ShopHub" for portfolio use and includes utilities to replace images with Unsplash placeholders and to upload images to Supabase.

Setup
- Install dependencies: npm install
- Run dev server: npm run dev
- Build: npm run build

This repository is intended as a portfolio-ready template. Remove demo credentials before deploying.
